**卡片 2**
- 标题：CPU 的多级 cache
- 核心知识：CPU 引入 L1、L2、L3 多级 cache，越靠近 CPU 的容量越小、速度越快。
- 简明解释：数据第一次被读取时会复制一份到 cache；再次访问同一数据就能直接命中（cache hit）。
- 例子或自测问题：自测——原文说多级 cache 中，越靠近 CPU 的两项特征分别是什么？

**卡片 3**
- 标题：局部性（locality）
- 核心知识：locality（局部性）分两种：temporal locality（时间局部性）与 spatial locality（空间局部性）。
- 简明解释：时间局部性指刚访问过的数据很可能马上又被访问；空间局部性指访问了某个地址，往往也会访问它附近的地址。
- 例子或自测问题：自测——原文说 locality 有哪两种？各自是什么意思？

**卡片 4**
- 标题：cache miss 与替换策略
- 核心知识：访问的数据不在 cache 里称为 cache miss，此时需从 RAM 取数据并替换进 cache，所用规则叫替换策略（replacement policy）。
- 简明解释：原文举出的常见替换策略是 LRU（least recently used，最近最少使用）。
- 例子或自测问题：自测——原文把"访问的数据不在 cache 里"叫什么？替换时的规则又叫什么？
